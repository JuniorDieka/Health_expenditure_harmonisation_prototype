CHART OF ACCOUNTS - README
===========================

No single canonical chart of accounts is provided. Each country in
the pilot uses its own coding structure and level of detail:

  Country A - flat 7-digit codes (see ACCOUNT_CODE column)
  Country B - 6-digit codes; the second sheet 'Plan_comptable'
              of the Excel file lists them
  Country C - 7-digit codes (see coaCode field)

Part of the assessment is to decide how you will model this
heterogeneity: whether to introduce a per-country CoA table, a
canonical account model, a mapping table, or another approach.
